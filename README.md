## 🌌 Welcome to the Maneko Neki Universe

Maneko Neki Universe is an interactive digital experience that combines tarot, astronomy, programming, visualization, and storytelling into a connected creative ecosystem.

This project explores the relationship between symbolic systems, celestial cycles, and technology through interactive web applications.

---

# 🔮 Tarot Engine

The core of Maneko Neki Universe is an interactive tarot system powered by a custom card engine.

The engine includes:

* Complete tarot card database
* Major and Minor Arcana support
* Upright and reversed meanings
* Dynamic card selection
* Automated final readings
* Interpretation engine based on card meanings
* Personalized reading generation
* Multiple interactive tarot spreads
* Custom reading experiences
* Oraculum system for guided interpretations

The system analyzes the selected cards and creates an interactive final reading by combining:

* Card symbolism
* Position meaning
* Reading context
* Generated interpretations

# 🌙 Lunar Observatory

The Lunar Observatory explores Earth's Moon through programming and astronomical visualization.

Features include:

* Interactive Moon calendar
* Lunar cycle tracking
* Moon phase calculations
* Monthly lunar exploration
* Real-time Moon phase visualization

The system calculates lunar phases using astronomical cycle algorithms based on the 29.53-day synodic month.

# 🌠 Northern Light Research Station

The Northern Light Research Station is a scientific visualization tool connected to NOAA space weather data.

Using live astronomical information, the system monitors:

* Solar wind speed
* Solar wind density
* Geomagnetic activity
* Planetary Kp index
* IMF Bz measurements
* Aurora activity conditions

The project demonstrates how real scientific data can be transformed into accessible interactive experiences.
